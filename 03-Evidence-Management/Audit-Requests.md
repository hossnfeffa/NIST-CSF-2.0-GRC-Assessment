# PBC-2026-001 — External Assurance Evidence Requests

| Request | Evidence requested | Owner | Status |
|---|---|---|---|
| E-01 | Access control policy and approval history | Security | Received (simulated) |
| E-02 | Privileged account inventory and access review | IAM | Received (simulated) |
| E-03 | Reconciled inventory and ownership records | IT Operations | Partial |
| E-04 | Incident response plan and exercise report | Security | Partial |
| E-05 | Backup job history and restore test results | Infrastructure | Partial |
| E-06 | SIEM alert configuration and test results | SOC | Pending |

Evidence requests must specify assessment period, population, due date, custodian, and secure delivery method in a real audit. Redact sensitive details and restrict access. A policy establishes design intent; test records and representative samples support operation during a defined period.
