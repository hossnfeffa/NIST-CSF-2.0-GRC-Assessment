# 90-Day Cybersecurity Improvement Roadmap

**Status:** Proposed and approved in fictional final executive meeting; implementation is not complete.

| Window | Priority work | Responsible owner | Acceptance evidence |
|---|---|---|---|
| Days 1–30 | Validate recoverability through authorized restore test | Infrastructure Manager | Signed restore test report; recovery objectives comparison |
| Days 1–30 | Verify privileged account containment and test alerts | Security Manager / IT Operations | Config exports, test logs, exceptions |
| Days 1–30 | Confirm risk ownership, approvals and resources | CEO / IT Director | Signed decisions and updated register |
| Days 31–60 | Reconcile asset inventories and assign owners | IT Operations | Matching rules, exception log, reconciliation record |
| Days 31–60 | Approve recurring access review SOP and perform review | IT Director | Approved SOP, signed review, remediation tickets |
| Days 31–60 | Conduct incident response tabletop | Security Manager | Exercise report and actions |
| Days 61–90 | Validate monitoring coverage and alert effectiveness | Security Manager | Coverage map and test results |
| Days 61–90 | Reassess residual risks and update Current Profile | GRC Analyst / risk owners | Reassessment evidence, management sign-off |
| Days 61–90 | Report progress to executives | GRC Analyst | Executive status report |

Dependencies, resource limits and obligations may change sequencing. Critical exposures require immediate interim safeguards rather than waiting for a roadmap milestone.
